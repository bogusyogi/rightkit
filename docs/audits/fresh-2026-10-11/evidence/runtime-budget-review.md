# Runtime-budget review — 2026-10-11

## Verdict

**No continuously-running crate has fresh, installed-app, scale-run proof.** All 11 rule-listed crates lack `## Runtime budget` in current README files. `rightkit-fsindex`, `rightkit-watch`, `rightkit-sync`, & `rightkit-daemon` have macOS-only source harnesses, but no fresh `RESULT` artifact exists. `rightkit-process` is omitted despite `StallWatchdog`; `rightkit-models` owns long-lived model-use leases & is omitted too.

This review used current source, checked-in non-audit evidence, & passive process samples only. No build, test, bench, network, installed-app action, or product change ran. Baseline commit: `f60f116514467e83952f5e5c12a71b34e3341389` ([initial-state.json](initial-state.json#L2-L8)).

## Gate & adoption gaps

1. `right-release publish cargo` invokes runtime-budget check ([publish-cargo.mjs](../../../packages/release/publish-cargo.mjs#L49-L69)), but checker itself only searches README text for resident/CPU/`Measured` syntax ([runtime-budgets.mjs](../../../packages/release/runtime-budgets.mjs#L88-L109)); it explicitly does **not** run bench ([runtime-budgets.mjs](../../../packages/release/runtime-budgets.mjs#L1-L6)). It omits required absolute ceiling, disk-op figure, exposed runtime values, artifact, scale proof, process/models membership, & benchmark fidelity.
2. Gate is cargo-publication scoped. `rightkit-daemon` & `rightkit-send` set `publish = false` ([daemon Cargo.toml](../../../crates/rightkit-daemon/Cargo.toml#L1-L10), [send Cargo.toml](../../../crates/rightkit-send/Cargo.toml#L1-L13)); they can reach app adoption without this cargo publish path.
3. Adoption registry records version states, while project lifecycle defines adoption as app pin ([README.md](../../../README.md#L41-L46)); neither records required installed-app figures. Current passive app samples therefore leave all 13 owners unqualified for scale adoption.
