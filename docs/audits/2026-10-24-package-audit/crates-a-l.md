- `registry.cargo` equals Cargo.toml `version` for all 34 publishable crates in range (rightkit-align is publish=false and absent). crates.io agrees: every one of those 34 versions is live and not yanked.
- Commit columns: `last-src` = `git log -1 -- crates/<dir>`; `-S ver` = the exact `git log -S'version = '` you specified; `-G ver` = `git log -G'^version = "'` (the package version line only). The -S form is unreliable here: it also fires on dependency lines and picks the repo-wide rustfmt sweep bbdf6ab (06:47Z 2026-10-23) for most crates. Treat -G as the real version commit. History is only 60 commits, so most crates show bbdf6ab or b98c3e7 (the rename sweep) rather than a meaningful bump commit.
- "source changed since" compares the dir against the -S/-G commit, and for the publish-time question compares commit time against crates.io `created_at`. - known-red: ci/known-red.json is `{"macos": {}, "windows": {}}`: no crate in range has an entry.
- "cargo package" column is a manifest read only. Whether it passes is UNVERIFIED (cargo not run). All 34 current versions were evidently packaged and published earlier, but the tree may have drifted since.
