New findings continue numbering:

7. **P1 — Saving weakens existing file permissions.** [commit.rs:67](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/commit.rs:67) creates replacement with default permissions, then renames it over original without copying security metadata. On macOS, private `0600` PDF becomes `0644` under umask `022`; Windows replacement inherits directory ACL instead of retaining PDF’s explicit restrictions. Platform semantics: [Rust creation modes](https://doc.rust-lang.org/std/os/unix/fs/trait.OpenOptionsExt.html), [Windows security descriptors](https://learn.microsoft.com/en-us/windows/win32/fileio/file-security-and-access-rights). **Fix:** create temporary file exclusively with restrictive access, preserve original mode/ACL before writing sensitive bytes, & verify permissions survive replacement on both platforms.

8. **P1 — Hard-link sibling tokens still overwrite successful commits.** [commit.rs:344](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/commit.rs:344), [349](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/commit.rs:349), [save.rs:549](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/save.rs:549). Stage two candidates against A; hard-link B to A; commit both to B. First rename disconnects B from A. Invalidation compares against B’s **new** identity, leaving A’s sibling token alive. Second commit treats B as Save As, skips SHA checking & overwrites first result. Applies on macOS & Windows, even sequentially. Existing regression only covers external in-place rewrite. **Fix:** capture source aliases matching destination’s pre-replacement identity under lock & invalidate those tokens after success, alongside post-replacement aliases; add two-token hard-link regression.

9. **P1 — Changed-font replacement moves untouched neighboring text.** [compose.rs:956](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/compose.rs:956) deletes glyph bytes without preserving their pen advance. For `BT /F1 12 Tf 72 700 Td (AB) Tj 1 0 0 rg (CD) Tj ET`, color change creates separate islands ([inspect.rs:2622](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/inspect.rs:2622)). Redraw AB in catalog font: CD shifts left by AB’s original width, potentially underneath replacement. Page-level substring verification misses this ([save.rs:446](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/save.rs:446)). **Fix:** replace removed glyph advances with equivalent positioning adjustments; regression must assert unchanged CD coordinates.

10. **P1 — Repeated content references exhaust memory before budgets run.** [inspect.rs:410](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/inspect.rs:410) decompresses & retains every `/Contents` entry independently before walking. Reference one compressed 16 MiB whitespace stream 1,024 times: inspection retains roughly 16 GiB although every stream satisfies its limit. Glyph/operation budgets never intervene. Both platforms affected. **Fix:** enforce aggregate decompression budget before allocation, process streams incrementally & avoid duplicate retained buffers; add repeated-reference hostile fixture.

11. **P1 — Glyph allocation precedes new glyph limit.** [inspect.rs:555](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/inspect.rs:555) reserves `bytes.len()/width` complete `DecodedGlyph` records before budget checking at [569](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/inspect.rs:569). One compressed `Tj` containing 64 MiB of single-byte codes requests multiple GiB despite two-million-glyph cap, risking allocation abort before typed refusal. **Fix:** reject operand glyph count exceeding remaining budget before reservation & use fallible bounded allocation; add oversized-single-operand regression.

12. **P2 — New wrappers invalidate later commands within same batch.** [compose.rs:1292](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/compose.rs:1292) prepends stream, shifting every original `contents_index`; that index participates in island digest ([model.rs:952](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/model.rs:952)). Consequently `[AddText, ReplaceSourceText]`, or two independent changed-font replacements on same page, fails fresh lookup with `SourceDigestMismatch` ([compose.rs:266](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/compose.rs:266)). **Fix:** validate original locators before mutation & defer wrapper installation until batch completion; add mixed-command & multiple-replacement regressions.
