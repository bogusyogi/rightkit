Public API changes
BREAKING
- LlmError::Status gains field retry_after: Option<Duration> (struct-literal builders need it; patterns naming every field need ..). Existing tests/call_options.rs, tests/raw_capture.rs, breaker.rs, openai.rs were updated.
- LlmError gains variant IncompleteOutput{cause, partial} (exhaustive matches need an arm; only returned when a StreamPolicy is set).
- generation::ImageRequest gains count, output_format; generation::ImageRoute gains output_formats, provider, base_url and sizes becomes Vec<ImageSize> (JSON still strings).
- OpenAiCompatProvider/AnthropicProvider internals: authorize/request signatures are private; no public signature broke.

- with_stream_policy / with_request_auth on the providers; with_cache_plan + anthropic::build_body_with_plan; cache::{CacheControlPlan, CacheAnchor}.

- new Cargo features: async (rightkit-http/async, futures-util, tokio timers), oauth (rightkit-oauth with secrets).
