**14. P1 — Positive directory cache confuses inode durability with link durability.** New key contains only device, inode & birth time at [atomic.rs:925](/Volumes/D/claude/rightkit/crates/rightkit-fs/src/atomic.rs:925); cache hit suppresses synchronization at [:937](/Volumes/D/claude/rightkit/crates/rightkit-fs/src/atomic.rs:937). [Apple fsync API](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man2/fsync.2.html).
