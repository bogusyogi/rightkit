1. **P1 — New TJ tracking can exhaust memory.** [inspect.rs:1867](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/inspect.rs:1867), [inspect.rs:1998](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/inspect.rs:1998). With valid font selected, `[(A) 0 () 0 () … (B)] TJ` containing 50,000 empty strings retains increasingly large copies of `trailing` in `spacing`: approximately 1.25 billion `GapNumber` entries, or 20 GB. **Fix:** skip empty operands before cloning/storing provenance; transfer accumulated numbers only when actual glyphs appear.

2. **P1 — Font insertion erases inherited resources.** [compose.rs:1345](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/compose.rs:1345), [compose.rs:1359](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/compose.rs:1359). If `/Resources` exists only on `/Pages`, `AddText` creates page-local resources containing only its new font. Existing `/F1` text & XObjects become unresolved; save verification can still find added text & accept output. **Fix:** resolve nearest inherited `/Resources` through bounded traversal, clone it, then add new font.

3. **P1 — `Q` restores wrong font state.** [inspect.rs:1685](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/inspect.rs:1685). Use `BT /F1 10 Tf ET q BT /F2 10 Tf ET Q BT 72 700 Td (B) Tj ET`. Renderer restores F1; walker retains F2. Let both map 66→B, but F1 map 67→C & F2 map 67→Z. Replacing B→Z writes 67, displays C & passes shared readback. **Fix:** stack/restore text-state parameters alongside graphics state, excluding text matrices.

4. **P1 — Word spacing still follows Unicode instead of encoded bytes.** [inspect.rs:2056](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/inspect.rs:2056), [compose.rs:670](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/compose.rs:670). Use simple-font `/Differences [32 /x 97 /a /b]`, positive 500-unit widths, 10-point size & `10 Tw`. Replace `aab`→`axb` within 15-point bounds. Encoding writes byte 32 for x; actual width becomes 25 points, while prediction & readback report 15. **Fix:** apply `Tw` only to single-byte code 32 throughout decoding, measurement & replacement deltas.

5. **P1 — Concurrent commits silently lose edits.** [save.rs:409](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/save.rs:409), [commit.rs:61](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/commit.rs:61). Stage two candidates against identical source. Both threads consume tokens & read original bytes before either renames; both return success, second overwrites first. Mutex protects token removal only. **Fix:** serialize commits by destination identity across source recheck, replacement & sibling-token invalidation. Existing [conflict test:258](/Volumes/D/claude/rightkit/crates/rightkit-pdf/tests/e2e.rs:258) changes source before commit, missing this interleaving.

6. **P1 — Path aliases bypass conflict checking.** [save.rs:412](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/save.rs:412). Stage `/tmp/memo.pdf`, externally modify it, then commit to `/tmp/./memo.pdf`: string inequality skips SHA verification & overwrites newer bytes. Windows case variants produce equivalent failure. **Fix:** compare normalized filesystem identities before deciding whether source recheck applies.

7. **P1 — Appended text inherits invisible rendering state.** [compose.rs:1523](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/compose.rs:1523). Source ending `BT /F1 10 Tf 3 Tr (hidden) Tj ET`, followed by `AddText("Approved")`, leaves added text invisible. New block sets font/color/matrix but never resets `Tr`; structural verification still extracts “Approved”. **Fix:** explicitly initialize rendering mode, spacing, horizontal scale & rise for generated text.

8. **P2 — CID width work remains unbounded across ranges.** [inspect.rs:1246](/Volumes/D/claude/rightkit/crates/rightkit-pdf/src/inspect.rs:1246). `/W` containing 40,000 repetitions of `0 65535 500` performs 2.62 billion insertions despite tiny final map. **Fix:** enforce total assignment budget, as CMap parsing already does.
