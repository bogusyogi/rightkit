# RightKit dependency and inventory audit, batch 2

Date: 2026-10-08. Scope: rightkit-framed-sidecar, rightkit-fs, rightkit-hotkeys, rightkit-http, rightkit-jobs, rightkit-license, rightkit-llm, rightkit-logs, rightkit-mcp, rightkit-media, rightkit-models, rightkit-oauth.
Read-only audit. No source, manifest, or lockfile was edited. Nothing committed.

## Method and caveats

- **Trees (measured).** `rightkit cargo tree -p <crate> -e normal,build --prefix depth --no-dedupe`, with default features and with `--no-default-features`. Dev-dependencies are excluded from runtime counts.
- **Workspace snapshot.** `crates/rightkit-align` is a directory with no `Cargo.toml` (created 22:22 today). Cargo refuses to load the workspace while it exists. I did not edit it. I copied `Cargo.toml`, `Cargo.lock` and `crates/` (minus `rightkit-align`) to `scratchpad/audit2/ws/` and ran the trees there. The copied lock matched the repo lock except for a `rightkit-compose` entry, so the resolved graphs of these 12 crates are the same as in the repo at copy time. The repo `Cargo.lock` has since been changed by other workers (new `jsonschema`, `rightkit-contracts`, `rightkit-compose` entries). The numbers below describe the copy-time graph.
- **Windows target not measurable.** `--target x86_64-pc-windows-msvc` is refused by the broker ("managed Rust target must be registered by broker"). Windows-only deps are therefore **estimated** from the `Cargo.lock` dependency graph (all optional edges counted). Marked "estimated".
- **"Crates added"** = unique name+version pairs reachable only through that direct dependency (set difference across the direct children's `--no-dedupe` subtrees). It includes the dependency itself. **Measured.**
- **Duplicates** = a crate name present at more than one version in the `Cargo.lock` (789 packages in the repo lock at audit time; multi-version names listed from the lock).
- Use sites were grepped in `src/`, `build.rs`, `examples/` and `tests/` where stated. Max 5 cited per dependency; "UNUSED" only after a whole-crate grep.

## Cross-cutting notes from this batch (short)

Full cross-cutting sections G to K are outside this assignment and are not repeated here. Items found while auditing these 12 crates:

- **Two sha2 majors:** 0.10 (most crates) and 0.11 (models hash.rs:1; suite/manifest.rs:6).
- **Two framing/JSON-lines paths:** rightkit-framed-sidecar (length_prefixed.rs, lib.rs) and inline JSON-lines in rightkit-mcp client.rs:196-201 and rightkit-oauth lib.rs:702. Not verified in full.
- **Security defect:** rightkit-mcp server.rs:249-252 and 934 (zero-filled token on RNG failure).
