## 0. Findings that change the brief (read first)

1. **The branch is 54 commits ahead of main, not 44.** The local clone is shallow: `484d5d0` (first commit visible, "Use dictation-ui CompactSettingsGroup") is a graft root and its parent `a62f6f9` is absent, so `git rev-list origin/main..efcc0aa` gives 44 and `git merge-base` prints nothing. `gh api repos/bogusyogi/heardright/compare/main...efcc0aa` says `ahead_by 54, behind_by 0, merge_base 72fedbd` (= `origin/main` tip, so the branch is a clean linear extension of main). The 10 older commits were read through the API only (file lists with per-file +/-, commit bodies; no diff content): `2f534d0 21394ff 7118690 53b6229 bbe6ad4 42538fa 2e262df b9ddf74 dcad65e a62f6f9`. Locally `git show --stat 484d5d0` reports 3,716 files / +832,720 because it is diffed against the empty tree; the real stat (API) is 12 files +11 -83. Table B has all 54 rows, flagged `api` (10 + `484d5d0`) or `local`. Working data: `commits-all.json`, `commits.tsv`, `missing10.txt`, `c484.txt`.
2. **On main HeardRight already used the mandatory owners directly with a thin app layer** (`@rightkit/react-shell` `AppShell`, `settings-ui` `SettingsPanel`+`standardSections`, `onboarding` `Onboarding` with HeardRight's own steps, `legal-ui`, `platform-ui`, `theme`, `license`, `app-update`, `logs`): 21,533 lines of ts/tsx in 141 files. The branch takes that to 4,270 lines in 50 files by moving the screens, shell pieces, onboarding steps, settings sections and History into `@rightkit/dictation-ui`, whose own changelog says for every entry "Markup, classes, wording, storage and native calls equal HeardRight's shipped ..." (`rk/packages/dictation-ui/CHANGELOG.md` 0.2.3 to 0.2.7). That is the owner's "wrong" case, at about 13.8k lines.
3. **The Rust direction is right and large.** Four swaps are real capability moves (text pipeline, command host, parakeet-core, onnx-asr: -13.5k lines) with HeardRight kept as `configure_host()` identity config. But RightKit already has near-identical forks of most of the remaining HeardRight crates (section E): about 47.5k lines of HeardRight Rust sit in crates that exist in RightKit and are not adopted.
4. On the mandatory rows the branch is mostly version bumps plus a set of real owner-API adoptions (licence, Pro bridge, updates, daemon peer admission, roots, crash, HTTP). The 24 Rust KEEP commits and the 7 direct-owner JS KEEP commits do not depend on the REDO commits (section F).
