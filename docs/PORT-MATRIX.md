## How to read

Active migration scope is nine apps; Ember is deferred, SellRight is not applicable, and Legion is permanently outside the blanket migration. Pin currency does not establish behavioral adoption. Rows are RightKit packages, grouped by domain; columns are apps. A cell is a state token with the short detail in parentheses. `Rows` lists the mandatory-set rows (M1, M2, ...) a package owns for the default profile; `Latest` is the latest published version, with the staged version in parentheses when it differs; `To move from` counts the triage MOVE rows that name the package, per app.

**Class** of a package (Adrian, 2026-10-24):

- `foundation`: An owner in a mandatory-set row for the app's profile. Every app of that profile owes it unless a row is ruled not applicable.
- `add-on`: Any other published RightKit package.
- `tool`: Private or unpublished, or consumed only by non-app repos (legion, build tooling).

**Cell states** (these tokens and no others):

| State | Meaning |
|---|---|
| `current` | Exact pin equal to the latest recorded published version; pin currency does not prove adoption. |
| `range` | Range pin that admits the latest recorded published version. |
| `stale` | Pin behind the latest recorded published version, shown as pinned→latest. |
| `ahead` | Pin newer than the latest published version (staged or unreleased), or no published version is recorded. |
| `local` | Path, workspace or git dependency, or a requirement that cannot be resolved to a registry version. |
| `missing` | Foundation owner required for the app's profile, with no pin and no N/A ruling. |
| `n/a` | Ruled not applicable for this app; the mandatory-set row id is shown. |
| `exception` | No pin, and an ownership exception names this package or its capability; issue and expiry are shown and EXPIRED or a missing issue or expiry is flagged. |
| `unused` | Add-on with no pin. |
| `not present` | The app directory does not exist on this machine. |

**Progress figure.** One figure per app: foundation owners pinned current divided by foundation owners required for the app's profile. An owner is required unless every mandatory-set row it belongs to is ruled not applicable for the app; it is pinned current when the worst of its pins in that app is `current` or `range` (one `stale`, `local` or `ahead` pin makes it not current). A foundation row is declared when every one of its owners has a registry pin, ruled when the app rules it not applicable, and open otherwise; an open row lists the owners it still misses. Add-on pins are reported next to the figure and never folded into it.

**Exceptions** come from `.rightkit/ownership-exceptions.json`. One that names a package or its capability shows on that package's cell for that app: as the state `exception` when the app has no pin, as a note when it does. `EXPIRED`, `no issue` and `no expiry` are flags. Exceptions that name neither a RightKit package nor a catalog capability (the dependency allowlist, for example) count in the per-app totals and appear on no cell.

**Domains** are a grouping kept in `scripts/generate-port-matrix.mjs`; the ownership catalog names capabilities but no domain. `RightKitSwift` is one row whose cell is the worst pin among the app's Apple targets (every `project.yml` and `Package.swift` that references it, test-only paths excluded); its latest version is the recorded published version in `rightkit-versions.json`. An Apple target's pin kind is `tag` (an exact or `from` version), `branch`, `path` or `revision` (url plus revision); only a tag can be `current`, `range`, `stale` or `ahead`, the others are `local`.

**RK-ready** packages are packages living inside an app repo whose package or directory name starts with `rightkit-`, `@rightkit/` or `RightKit`: built so they can be published. **To move** rows are the MOVE verdicts of the triage file, counted per target package.
