# rightkit-social-publish

Social platform publish adapters (X, Bluesky, Mastodon, Threads, Instagram, Facebook, LinkedIn, Pinterest, TikTok, YouTube) with a no-retry HTTP layer, Retry-After parsing, media checks, pinned API versions and error-text redaction.

Moved into RightKit from PostRight (postright-engine publish adapters, http, media, platform, api_versions; postright-protocol publish payload) on 2026-11-01.
