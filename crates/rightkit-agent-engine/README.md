# rightkit-agent-engine

Typed contracts for an always-on agent: task envelope and its ten statuses with legal transitions, principals,
intent provenance, effect classification, portable device references, approval binding and the voice hand-off.
Serde types and pure functions only: no runtime, journal, IPC or effects.

Moved into RightKit from `pulse-core` (`agent` module) on 2026-11-01.
