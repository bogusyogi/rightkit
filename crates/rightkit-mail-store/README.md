# rightkit-mail-store

Mail store over SQLCipher: encrypted open with key candidates and lifetime lock, versioned schema and migration gate with backup, accounts, labels, threads, search adapter, outbox and pending queues, sync apply and the local semantic index.

Moved into RightKit from MailRight (src-tauri db/*, db_schema, db_sync_apply, attach_cache, safety) on 2026-11-01.
