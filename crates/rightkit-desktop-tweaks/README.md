# rightkit-desktop-tweaks

Desktop tweaks for Windows: the global keyboard layer with Mac-style editing shortcuts (Alt acts as Ctrl for a set of keys), screenshot hot keys, a hook hub other features register with, and key injection. Windows only; empty elsewhere. The application installs `services::Services` for the screenshot, snippet, wheel and burst hooks.

Moved into RightKit from `pulse-windows` (Pulse) `keys.rs` on 2026-11-01. The Swift tweaks (Finder, window actions) are owned by the Swift packages.
