# rightkit-code-audit-qualification

Qualification tooling for the code audit engine: fixture bench scoring (`bench`), semantic capsule bridge (`capsule`), assurance qualification record validation (`assurance`) and security-control observation (`security_controls`). Hosts wire each `run` entry into their own CLI. `data/build-fixtures.sh` rebuilds the bench fixture bundles.

Moved into RightKit from Legion (`legion-dev` audit modules) on 2026-11-01.
