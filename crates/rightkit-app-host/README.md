# rightkit-app-host

Host services a desktop app gives the RightKit companion crates moved out of Pulse (`rightkit-chat-bridge`, `rightkit-ai-accounts`, `rightkit-owner-approvals`, `rightkit-remote-gateway`, `rightkit-web-session`): its state folder, the account home, its product name and what its UI last published. The app calls `install` once at start; until then the crates see a neutral host with no state folder.

Optional, not part of the mandatory set: an app needs it only when it embeds one of those five crates, and it is not on `packages/release/ownership-mandatory-set.json`. It is one small trait (`AppHost`, every method defaulted) and does not repeat another crate: `rightkit-tauri-shell`, `rightkit-instance` and `rightkit-app-settings` keep no process-wide host, `rightkit_agent_config::state_root` computes an agent app's `Orthic Labs/<name>` root from `rightkit-roots` (an app that has one returns it from `AppHost::state_root`), and the profile-aware home and environment come from `rightkit-fs` (`profile_home`), which this crate calls.
