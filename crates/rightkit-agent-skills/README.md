# rightkit-agent-skills

Agent skills and slash-command grammar: skill discovery, manifests, the shared command table and interactive effects

Moved into RightKit from `coderight-skills` (CodeRight) on 2026-11-01.

The host names itself once through `rightkit-agent-config` (`set_env_prefix`, `set_app_name`, `set_state_dir_name`, or `ensure_host_names`); the command table, its texts and the `metadata:` key of a `SKILL.md` follow those names at use. Default host: command-line name `rightkit`, display name `Agent`.
