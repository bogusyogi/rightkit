# @rightkit/mail-ui npm consumer (npm.@rightkit/mail-ui)

Packed-archive consumer for `@rightkit/mail-ui` (the workspace version, from `RIGHTKIT_CONSUMER_EXPECTED_VERSION`). The unit is installed only from the sealed `file:` archive; the reviewed closure pins `react` 19.3.1, `react-dom` 19.3.1, `@rightkit/legal` 0.6.3, `@rightkit/license` 0.3.0, `@rightkit/logs` 0.1.6, `@rightkit/onboarding` 0.6.3, `@rightkit/pdf-ui` 0.2.0, `@rightkit/platform-ui` 0.4.0, `@rightkit/react-shell` 0.7.2, `@rightkit/settings-ui` 0.7.0, `@rightkit/theme` 0.3.1, `@rightkit/workspace-ui` 0.2.1 (needs 0.2.1 on npm; until then the run overrides it with the packed archive). Declared-only dependencies: `@tanstack/react-virtual`, `@tauri-apps/api`, `@tiptap/core`, `@tiptap/extension-color`, `@tiptap/extension-font-family`, `@tiptap/extension-image`, `@tiptap/extension-text-style`, `@tiptap/react`, `@tiptap/starter-kit`, `dompurify`, `tailwindcss`, `zustand`.

Surface (exact `exports` keys): `.`, `./components/AccountSwitcher`, `./components/Icons`, `./hooks/dialog`, `./lib/ipc`, `./lib/ipc/agentApprovals`, `./lib/mail`, `./lib/preferences`, `./lib/visibleText`, `./package.json`, `./store/index`, `./store/types`, `./styles.css`.

Scenario (1): the installed manifest is the reviewed package and its export keys match; the root entry imports and exposes `setHostAppName`, `hostAppName`, `AccountSwitcher`, the workspace host (`mailWorkspaceHost`, `mailWorkspaceClient`), `MailWorkspaceProvider` and the five ready workspace views (`CalendarView`, `TasksView`, `DriveView`, `ContactsView`, `MeetView`; `MailWorkspaceProvider` hands `mailWorkspaceHost` to workspace-ui's `useWorkspaceHost`, and none of the five views fails with workspace-ui's `MISSING_WORKSPACE_HOST_PROVIDER`), and no longer exposes the workspace navs, `useDrive` or the calendar helpers (they are `@rightkit/workspace-ui`'s).

Required environment: `RIGHTKIT_CONSUMER_ARTIFACT`, `RIGHTKIT_CONSUMER_ARTIFACT_SHA256`, `RIGHTKIT_CONSUMER_EXPECTED_VERSION` and `RIGHTKIT_CONSUMER_RESOLUTION` (`packed` or `fetched`). `provenance.mjs` is the shared byte-identical helper that binds every installed file to the supplied archive. No network, no credentials. Output is one JSON line; `nativeHostQualified` is always false.
