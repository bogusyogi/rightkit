# @rightkit/video-ui npm consumer (npm.@rightkit/video-ui)

Packed-archive consumer for `@rightkit/video-ui` 0.2.1 (the workspace version). The unit is installed only from the sealed `file:` archive; the reviewed closure pins `react` 19.3.1, `react-dom` 19.3.1, `@rightkit/app-update` 0.4.3, `@rightkit/ci` 0.3.2, `@rightkit/legal` 0.6.3, `@rightkit/legal-ui` 0.4.2, `@rightkit/license` 0.3.1, `@rightkit/logs` 0.1.6, `@rightkit/media-ui` 0.3.6, `@rightkit/onboarding` 0.6.4, `@rightkit/outdated` 0.3.1, `@rightkit/platform-ui` 0.4.1, `@rightkit/react-shell` 0.7.3, `@rightkit/release` 0.6.52, `@rightkit/settings-ui` 0.7.1, `@rightkit/tauri` 0.4.0, `@rightkit/tauri-shell` 0.1.4, `@rightkit/theme` 0.3.2. Declared-only dependencies: `@tauri-apps/api`, `@tauri-apps/plugin-dialog`, `@tauri-apps/plugin-process`, `@tauri-apps/plugin-updater`.

Surface (exact `exports` keys): `.`, `./app`, `./app.css`, `./package.json`, `./styles.css`, `./tauri`.

Scenario (1): the installed manifest is the reviewed package and its export keys match; the root entry imports and exposes `installVideoHost`, `videoHost`, `TimelineEditorView`, `Timeline`, `NativePlayer`, `engineCall`, `projectShow` and `timecode`, and none of the app shell (`setHostAppName`, `hostAppName`, `Home`, `SettingsView`, `DesktopWorkspace`); `videoHost()` refuses before a host is installed; after `installVideoHost`, `engineCall` goes through the host's engine and `assetUrl` through its `assetUrl`. The `./app` entry (same module instance as the root) exposes CutRight's app (`DesktopWorkspace`, the pages, `OnboardingGate`, `configureLegal`, `setHostAppName`, `themeStore`, `shellBridge`, `mediaAdapters`, `logs`, `licenseClient`, `updates`, demo mode, pickers, `videoAppHost`); `videoAppHost()` refuses while the host has no `app` part; with one, `demoStatus` goes through its `invoke('demo_status')` and `pickFolder` through its `pickFolder`. The `./tauri` entry's `tauriVideoHost()` builds without touching Tauri and carries every host part, the `app` part's functions included.

Required environment: `RIGHTKIT_CONSUMER_ARTIFACT`, `RIGHTKIT_CONSUMER_ARTIFACT_SHA256`, `RIGHTKIT_CONSUMER_EXPECTED_VERSION` and `RIGHTKIT_CONSUMER_RESOLUTION` (`packed` or `fetched`). `provenance.mjs` is the shared byte-identical helper that binds every installed file to the supplied archive. No network, no credentials. Output is one JSON line; `nativeHostQualified` is always false.
