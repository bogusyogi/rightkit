# rightkit-notch-ui 0.1.0 registry consumer

Standalone package outside the RightKit workspace. It depends on `rightkit-notch-ui` by exact registry pin
(`=0.1.0`) with default features. It has no path, Git, workspace or patch dependency and no
committed `Cargo.lock`.

Layout cell count, spring rest and step, and the hover emphasis scale. Windows modules are not used and no window or timer is created.

Proof row: layout and motion values. Each check prints an `ok:` line; a failed check prints `FAIL:` and exits 1.
No network, no real user data, no process spawn.
