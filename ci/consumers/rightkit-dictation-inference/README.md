# rightkit-dictation-inference registry consumer

Standalone consumer pinning `rightkit-dictation-inference` to the exact version in its
`Cargo.toml`. Through the public API only, it proves: the beam emission reward is a finite,
non-negative default, and a denied file read produces the typed `E_PERMISSION` error naming the
configured app.

State: in-memory values only. No model, no audio, no network. Run only by the CI consumer lane.
